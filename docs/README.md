# Strydr documentation

Strydr is a self-hosted web app that turns Apple Watch workouts and Apple Health metrics into running analytics and
home-workout tracking. These pages cover setting it up, getting data in, what every screen does, and how the numbers are
worked out.

## Start here

1. [Getting started](getting-started.md): what you need and the shortest path to your first synced run.
2. [Installation](installation.md): Docker on Linux, the Windows installer, remote syncs, backups and upgrades.
3. [Importing data](importing-data.md): Health Auto Export automations and the free Apple Health export.

## Using Strydr

- [Feature tour](features.md): every page, with screenshots.
- [Home workouts](home-workouts.md): kettlebell and bodyweight plans, the live screen and progress.
