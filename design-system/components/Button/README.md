Four button treatments, each a fixed-height pill (`radius-full`) — Strydr has no rectangular button.

**Primary** (`btn btn-primary`) is the only button in solid `accent`, with `ink-on-accent` text — use it once per screen for the one action that matters (sync with the watch, save a route). Strydr reads data recorded elsewhere, so there's no "start" action anywhere in this button set. **Glass** (`btn btn-glass`) is the default for everything else: it sits directly on the page's glass panels without adding another shadow layer. **Secondary** (`btn btn-secondary`) is a hairline outline for a de-emphasized or destructive-adjacent action (cancel, discard). Add `btn-icon` to any variant for a 48×48 icon-only button, and `btn-sm` for a 36px compact size inside a tight row (a filter chip row, a card header).

Every button provides its own label — text, an icon with `aria-label`, or both; never color alone. Disabled buttons drop to 45% opacity and lose the press/hover transform — don't also gray out their text color, the opacity already does that job. Press feedback is a `scale(.97)` over `cubic-bezier(.22,1,.36,1)`, 160ms — the same spring curve used everywhere else a surface responds to touch. Focus (keyboard, not pointer) always shows the `focus-ring` outline plus `shadow-focus`; never remove it.
